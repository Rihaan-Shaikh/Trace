# TRACE Evaluation Framework

Specifies the evaluation benchmarks outlined in Project Bible Section 25:
- 15–20 scripted decisions on NovaMart.
- Verification accuracy scoring (analytical recalculation vs primary calculation).
- Sandbox correctness (sensitivity consistency and boundary checking).
- Lapse condition precision (root-solved thresholds vs empirical breach points).
- Loss History Ledger error calibration over time.
